# 02 · Getting Started with TallyPrime

**TallyPrime** is India's most widely used accounting software for small and medium businesses. This module installs it, creates your practice company, and teaches the navigation and shortcuts you'll use every day.

## 1. Install and choose a mode

1. Download TallyPrime from **tallysolutions.com** and install it on Windows.
2. Without a licence, choose **Work in Educational Mode** — all features work, but voucher dates are limited to the 1st, 2nd and 31st of a month. That's enough for learning; use those dates in exercises.
3. Licensed users can activate a single-user or multi-user licence; TallyPrime also offers remote and cloud access options.

## 2. Create the company

1. On the start screen choose **Create Company** (or press **Alt+K → Create**).
2. Fill: **Company name** "Sri Sai Traders", mailing name, address, State **Telangana**, Country India, pincode, phone, email.
3. **Financial year beginning from**: 1-4-2026; **Books beginning from**: 1-4-2026.
4. Base currency: ₹ (INR) is set by default.
5. Optionally set a **TallyVault password** (encrypts data — never forget it; it cannot be recovered).
6. Press **Ctrl+A** to accept. TallyPrime asks whether to enable GST and other features now — you can do it later via **F11**.

## 3. Navigating TallyPrime

1. **Gateway of Tally** is the home screen with three sections: **Masters** (Create, Alter, Chart of Accounts), **Transactions** (Vouchers, Day Book), **Utilities** and **Reports** (Balance Sheet, Profit & Loss, Stock Summary, Ratio Analysis, Display More Reports).
2. **Go To (Alt+G)** opens a search box from anywhere — type "Ledger", "Sales", "Balance Sheet" and press Enter. It's the fastest way to move.
3. The top menu bar holds **Company (Alt+K)**, **Data (Alt+Y)**, **Exchange (Alt+Z)**, **Go To (Alt+G)**, **Import (Alt+O)**, **Export (Alt+E)**, **Share (Alt+M)** and **Print (Alt+P)**.
4. The right-hand **button bar** changes with each screen — e.g. **F2** date, **F11** features, **F12** configure.
5. **Esc** goes back; **Ctrl+A** saves/accepts; **Alt+C** creates a master (like a new ledger) while you're inside a voucher.

## 4. Features and configuration

1. **F11 (Company Features)** turns on capabilities: Maintain Inventory, Enable GST, Enable TDS/TCS, Payroll, Cost Centres, Multiple Currencies, Bill-wise entry.
2. **F12 (Configure)** changes how a screen behaves — e.g. show more fields in vouchers or more columns in reports.
3. Keep features minimal at first; enable more as the course introduces them.
4. Company management — select, shut, alter or create companies — lives under **Alt+K (Company)**; you can keep several companies open and switch between them.

## Cheat sheet

| Shortcut | Action |
|---|---|
| Alt+K | Company menu (create, select, alter) |
| Alt+G | Go To (search any screen) |
| Ctrl+A | Accept / save |
| Esc | Back / cancel |
| Alt+C | Create master on the fly |
| F2 / Alt+F2 | Change date / period |
| F11 | Company features |
| F12 | Configure screen |
| Alt+P / Alt+E | Print / Export |

## How It Actually Works

TallyPrime stores each company as a data folder on your computer (path shown under **Alt+Y → Data** settings). Every voucher you save updates the underlying ledgers and stock records immediately, so reports are always current — there's no separate "posting" step. Features you enable with F11 add fields and reports to the same data, which is why you can switch on GST or payroll later without starting over.
